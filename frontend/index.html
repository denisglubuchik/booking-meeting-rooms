Navigation Map

Карта навигации приложения

Этот блок можно редактировать прямо в HTML, чтобы уточнять состав экранов и связи между ними до переноса в компоненты.

Общие разделы

  • Вход → Дашборд
  • Дашборд → Найти комнату → Детали переговорной → Создать бронь
  • Офисы → Комнаты офиса → Детали переговорной
  • Мои бронирования → Перенос / смена комнаты / отмена
  • Профиль → Редактирование личных данных

Админ-маршруты

  • Офисы → создание / редактирование / активация
  • Комнаты → фильтры / редактирование / управление статусом
  • Бронирования → просмотр по статусам, пользователям и датам
  • Пользователи → роль / активация / деактивация

Ключевые сценарии

  • 1. Выбрать офис, дату и слот, затем увидеть свободные комнаты.
  • 2. Изучить офис и доступные переговорные без запуска поиска.
  • 3. Быстро понять свои ближайшие встречи и изменить активные брони.
  • 4. Для администратора: просматривать каталоги и управлять данными в табличных режимах.
